DÉPLOIEMENT
1. Décompresser ce ZIP à la racine du dépôt du site.
2. Remplacer les fichiers portant le même nom.
3. Déployer le frontend sur GitHub Pages et les fonctions sur Netlify.
4. Vérifier un paiement test SumUp avant ouverture.
5. Lire VALIDATION-FOURNISSEURS.txt et contrôler les frais de livraison France dans CJ avant d’activer les nouveaux produits en production.
6. Faire relire le règlement et les pages juridiques avant lancement réel du jeu concours.

IMPORTANT FOURNISSEUR
Les nouvelles références sont compatibles dropshipping chez CJ, mais l’automatisation de commande fournisseur n’est pas activée pour ces nouveaux SKU dans ce package : après paiement, la commande est enregistrée et doit être passée chez CJ manuellement jusqu’à ce que les variantes/logistiques exactes soient mappées dans l’API CJ.
